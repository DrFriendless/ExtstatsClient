The official Extended Stats approach is that if you played an expansion, then you also played a base game. We will look to see what that base game was, by looking for plays of possible base games on the same day. If you play Dominion with 4 expansions mixed in, that will count as 1 play, and as 1 play each of Dominion and each of the expansions.

Some players take the view that an expansion like (to choose from many examples) Carcassonne: Towers and Thieves implement such fundamental changes from the base game that they are like playing a different game with the same components. So a play of that expansion should count as only a play of that expansion, and not of the base game.

If you turn this option off and then reprocess plays on the Updates page, we'll do our best to present your data as if you are of the second view.

These are plays you've recorded on BGG for which we coudln't infer a base game. You can fix these by either adding a base game to your plays on BGG on the day, or by setting a default base game in the options above. Those changes will take effect when Extended Stats next downloads the play - in this case of historical plays you will need to initiate that on the Updates page.
