# ExtstatsClient

This repository holds the Angular widgets which create the interactive components of the site.
These components are compiled locally and deployed within the site infrastructure of the exstats-home repository.

## Feature Pages

A feature page is a page that fulfils the purpose of the site, i.e. it gives you board game statistics.

* CollectionWidget - the Collection page
* FavouritesWidget - the Favourites page
* GeekWidget - the small boxes with a few details that act as links to the more detailed feature pages, e.g. https://extstats.drfriendless.com/geek.html?geek=Friendless
* MonthlyWidget - the plays by month page
* MultiplaysWidget - the comparative plays page
* OwnedWidget - the owned games page
* PlaysWidget - the plays page
* RankingTable - the rankings table page
* WarTable - the war table page
* YearlyWidget - the yearly plays page

## Other Pages

* AdminWidget - the admin page
* CommentsWidget - the comments controls on the blog pages
* FAQWidget - the FAQ widget on the front page, and the "Where's My Page" box
* LoginWidget - the Login / Logout button with all the stuff that can happen there
* UpdatesWidget - the updates page where you can manage updating your BGG data
* UserWidget - the user page where you can manage data the page stores about you
