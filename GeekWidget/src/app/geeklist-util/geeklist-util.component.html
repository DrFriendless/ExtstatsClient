There are two hyperlinks in each line - the game name links to the BGG entry for the game, the remainder links to the entry on the geeklist.

Now you need to fill in the trade grid, to say what you'll accept for what you're offering. This app is designed to support this method (which is specific to the Australian maths-trade style):

  1. Use the outlined position combos in each wanted-game column header to move the games you want most to the left, and the games you want least to the right. There is a bug where sometimes the position combos wander off from the header box, please look around for stray ones!
  2. Use the outlined position combos in each offered-game row header to move the games you value most to the top, and the games you value least to the bottom.
  3. Fill in how much cash you will offer for each game you want.
  4. Fill in how much cash you will accept for each game you have.
  5. For each game you want to get, click the Accept box for the top game you'd accept for that. Because all of your games below that are worth less, you'd probably accept that game for any of them. Because all of the games you want to the left of that are worth more, you'd probably accept any of those games for this one.
