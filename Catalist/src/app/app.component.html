Use this page to compose new selectors. A selector is a criterion for selecting a set of board games. It can refer to features of the game, your tags, and data retrieved from BGG. Selectors can also be composed from other selectors. For more details, refer to the documentation.

The Store is a place where you can store selectors that you like or want to use later - these must be fully formed selectors with no missing values. The Chooser is a place which lists the selectors built-in to Extstats. These don't come with values - you will need to add those yourself. The Composer is where we display the selector currently being built.

This is what you do:

  • Choose a selector from the Chooser, or the Store
  • Configure it in the Composer
  • Save it into the Store
  • Selectors may be run from the Composer, producing results in the Selection Results

The "..." button means "if you choose a selector, it will be added here". However at the moment you can't have two "..." buttons in the composer - if you want to do something complex you'll need to build the selector from the bottom up by storing parts in the Store.
