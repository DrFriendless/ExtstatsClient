The Tagalogue (with apologies to the people of the Philippines) is the core page for managing which tags you have attached to which games. This is where you get to make new tags and delete unused tags. Once tags are defined you can add them here, or by using a minitag, which is a tiny tag which appears at the end of board game links on pages which support it. To see minitags you must be logged in and you must have at least one tag defined. You can then click on the minitag to quickly add and remove tags from that game.

The Tagalogue is not the place for seeing a nice list of all games with a particular tag. That functionality, along with better support for selectors, is in the Catalist.
